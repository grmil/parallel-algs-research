# parallel-algs-research

This library is a practice project to experiment with linear algebra types and
operations. Eventually the algorithms will be parallelized.

### Usage:

To build the example and test executables:
```
git clone git@github.com:grmil/parallel-algs-research.git
cmake -S . -B build
cmake --build build
```
The executables will be located in the ```build/``` directory.
